# VRM RETRO PAPERCRAFT

VRM アバター（0.x / 1.0）を開くと、**ペーパークラフトの展開図**（A4 の PDF）ができます。印刷して切って折って貼ると、身長 150〜260 mm の立つ紙のアバターになります。
画面では、紙の部品が折れて立ち上がる様子を 3D で見られます。

[VRM RETRO VIEWER](https://github.com/harukaappscreate/vrm-retro-viewer)、[VRM Motion Studio](https://github.com/harukaappscreate/vrm-motion-studio)、[VRM RETRO MAKER](https://github.com/harukaappscreate/vrm-retro-maker)、[VRM RETRO 4DGS STUDIO](https://github.com/harukaappscreate/vrm-retro-4dgs) の姉妹ツールです。ファイルは外に送りません。ブラウザ（または自分のパソコン）の中だけで読み、変換します。

## しくみ

1. **部位**：各頂点を、いちばん強く効いている骨の部位に分けます。頭（髪ごと）、胴（肩とスカートごと）、腕 2 本（手はミトン）、脚 2 本、足 2 つ。
2. **紙の立体（輪切り）**：部位ごとに、骨に沿った閉じた筒にします。6〜8 角形の輪を 3〜6 段、両端は平らなふた。各角の半径はアバターの表面から読みます（96 パーセンタイル）。細い腕や脚は、どの辺も 5 mm 以上になるよう少し太くします。
3. **色**：アバターの表面に約 24 万点をまいてテクスチャの色を取り、部位ごとに「いちばん外側の色」の地図（骨に沿って × 骨のまわり、ふたは別）にします。紙の各画素は、その点が 3D のどこに当たるかで地図を引くので、顔・服・靴が正しい場所に刷られます。
4. **展開**：筒の段ごとに 1 本の帯として広げ、背中（頭・胴）、下側（腕）、内側（脚）で切り開きます。いちばん太い段を背骨にして、ほかの段は継ぎ目の反対側でつなぎ、ふたは端の段につなぎます。重なる面は別の部品にします。
5. **のりしろ**：切る辺ごとに番号付きののりしろを付けます。「のりしろ N を、N と書いた辺の裏へ」。のりしろの場所がない辺は両側に番号を刷るので、内側からテープで留めます。
6. **ページ**：部品を回して低い箱にし、A4 に棚詰めします。実線＝切る、破線＝山折り、一点鎖線＝谷折り。色は切り線の外まで少しはみ出させ、白いふちが出ないようにしています。

**レトロ色**：色の地図を粗くし、24 色の共通パレットにします。

## アバターのライセンス

ペーパークラフトは改変したコピーです。改変禁止のアバター（VRM 1.0 の `modification: prohibited`、VRM 0.x の `*_ND`）は断ります。
再配布禁止のアバターは、PDF の各ページに「自分で印刷して使うだけ。PDF や完成品を配らない」と刷ります。
自分で作ったか使ってよいアバターだけを使ってください。他人のキャラクターは対象外です。

## 確かめたこと（サンプル、180 mm）

- 8 部位、16 部品、400 面、切る辺 244 本（のりしろ付きは約 222 本）、A4 2 枚。
- 各面は隣の面と共有する辺で平らに並べているので、貼り合わせる辺の長さは一致します。部品の中の重なりはなし（分離軸判定）、最短の辺 5.0 mm。
- 紙の立体と元のアバターの輪郭の重なり（8 方向）：0.74〜0.78。脚の間・スカートの下・指・髪の房が失われます。
- 時間（パソコンの Python）：読み込み 0.4 秒、紙の立体 0.5 秒、割り付け 0.3 秒、PDF 1.3 秒。
- まだ：実際に印刷して組むこと。

## 自分で動かす

Python 3 と Pyxel 3（`pip install pyxel numpy pillow`）。

```bash
python main.py                 # ウィンドウに .vrm をドロップ
python main.py avatar.vrm
```

キー：S PDF を保存（main.py の隣）、R レトロ色、上下 サイズ、F 折る / 開く、SPACE 一時停止、P スクリーンショット、G GIF。マウス：ドラッグで回す、ホイールで拡大。

itch.io 用：`python tools/build_web.py`（`vrm_retro_papercraft_itch.zip` を作ります）。
